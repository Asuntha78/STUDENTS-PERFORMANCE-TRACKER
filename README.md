# STUDENTS-PERFORMANCE-TRACKER
A students performance tracker which calculates the academic performance of a class.
# I used:
While loops
Lists
Condidtional statements
Python built-in functions such as sum(),count(),max(),min()
# Inputs:
Number of students
Names
Mathematics marks
Physics marks
chemistry marks
# It,
Creates individual academic records for each students
Calculates each students average and grades
Calculates the class average
Identifies students with highest and lowest average
Counts the number of students in each grade category
